Connect to your Google Sheet

Right now this page is running on demo data. Point it at your sheet's Web App URL and it will read and write the real thing.

  1. In the sheet, open Extensions → Apps Script and paste in WebApp.gs from the repo.
  2. Deploy → New deployment → Web app.
  3. Set Execute as: Me and Who has access: Anyone, then Deploy and authorize.
  4. Copy the Web app URL (ends in /exec) and paste it below.

The URL is stored in this browser only. Nothing is sent anywhere except your own Apps Script endpoint.

Delete this task?

This cannot be undone. The task is removed from Task Master and disappears from every view. Its completion history, alert dates and acknowledgment are deleted with it.

The deletion itself is recorded in the Escalation Log, so the audit trail keeps the fact that this task existed and was removed.
